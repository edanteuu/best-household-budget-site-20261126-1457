Nest Egg — the Marlowe household's budget book. A working household budget site that runs entirely from static files, with no network requests: a November 2026 dashboard (income, spending, savings rate, spending donut, budget bars, bills to pay, savings goals, recent transactions), a filterable transactions ledger with a working add form, thirteen editable budget envelopes, savings goals you can contribute to, a recurring-bills list you can mark paid, six months of reports, and a 50/30/20 planner with a what-if tool. Every figure is computed from the same transaction list, so the pages always agree; changes persist in the browser.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080. No build step, no dependencies.

## Hand it in

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
```

`main.ts` copies `app/` and `screenshots/` to the output directory and writes `dossier.json` with the vendored make.fun library.
